# Processed data for FIT2179 Data Visualisation 2

Topic: Australia's protected areas and species protection gaps.

These CSV files are reduced/aggregated versions of the original datasets so they can load quickly in Vega-Lite on GitHub Pages.

Total processed CSV size: 1.72 MB.

Recommended files for the final web page:
- `protected_areas_points.csv` for the main protected-area point map.
- `protected_area_state_summary.csv` for state/territory ranking.
- `protected_area_type_summary.csv` and `protected_area_iucn_summary.csv` for protected-area composition.
- `protected_area_timeline.csv` for the historical growth story.
- `species_status_summary_combined.csv` for the protection-gap comparison.
- `terrestrial_lowest_protected_regions_top20.csv` and `marine_lowest_protected_regions_top20.csv` for gap highlights.

Source notes:
- CAPAD 2024: Department of Climate Change, Energy, the Environment and Water.
- Species protection summaries: CSIRO Data Access Portal collection downloaded in the archive.
- Threatened ecological communities: DCCEEW extract dated 2026-03-20.
- World Heritage sites: UNESCO Australia-only extract.
